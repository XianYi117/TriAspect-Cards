# 元素卡牌對戰 v1.0.2

潮汐（藍）・森境（綠）・燼火（紅）網頁卡牌遊戲，依官方規則總覽實作。

## 線上遊玩

開啟本 repo 的 GitHub Pages（Settings → Pages → Source: Deploy from branch → main / root）後即可：

**https://xianyi117.github.io/element-card-battle/**

## 操作說明（對應官方規則）

1. **選擇牌組** → 開始
2. **召喚階段**：點手牌 →「轉為能量」累積能量，或「選擇召喚」選定本回合唯一角色
3. **支付能量**：確認支付（不足會自動從手牌/牌庫/生命牌補）
4. **發動效果**：點戰場單位 →「發動效果」支付效果費用
5. **戰鬥結算**：比較雙方戰鬥力（ATK+修正），較高者對對手造成等量生命牌傷害；平手各扣 1
6. **結束回合**：戰場卡進棄牌堆，手牌上限 7，抽 2 張進入下一回合

## 本地完整卡圖版

專案內含 54 張卡圖 PNG 的完整版，請在本地開啟 `index.html`。

## 規則重點

- 一組牌組固定 20 張
- 生命牌 6 張（從牌庫抽出）
- 每回合同時召喚 1 隻
- 先攻可出效果，後攻可干擾
- 強制召喚規則（牌庫頂 → 手牌 → 生命牌依序支付）
- 戰鬥後結算傷害並清空戰場
